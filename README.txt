پروژه APK کارگاه (جدا از پروژه انبار)

منبع فایل‌های وب: /mnt/data/kargah/  (index.html, manifest.json, sw.js, آیکون‌ها، logo.png)
این فایل‌ها داخل پوشه www/ کپی شده‌اند.

هر بار که index.html تغییر کرد:
  1. فایل‌های تغییر کرده را دوباره داخل www/ کپی کنید.
  2. این پوشه را در GitHub (repo: kargah-android) آپلود/به‌روز کنید.
  3. Actions را اجرا کنید و APK جدید را از بخش Artifacts دانلود کنید.

نکته: برای تغییر نام یا آیکون یا نسخه، باید APK دوباره ساخته و نصب شود.
